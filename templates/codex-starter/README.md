# Trace Codex Starter Template

这是可审查的冷启动协作模板，不会自动上传本地认知源、写入 Wiki、保存 prompt 或发布能力。它提供通用的“先理解当前工作、区分讨论与沉淀、proposal → adopt → commit、证据与范围优先”协作起点，而不是复制某个人的历史上下文。

包含：

- `agent-collaboration-governance@1.0.0`：预设能力引用；
- `trace-collaboration-starter@1.0.0`：来源路由和读取范围；
- `trace-default-governance@1.0.0`：沉淀 / 激活 receipt 与采用规则。

安装后生成用户项目本地 instance 和 lock。个人或团队适配必须创建自己的 profile / overlay；修改不会反写模板，也不会因模板或 Plugin 更新自动覆盖已有项目。
